# Mosaic-PL Methods Implementation Audit

Reviewed 2026-09-14 against the current source and representative CASP17 run
manifests, structures, and research annotations. Scope: protein-ligand pose
prediction. This is not evidence that every optional module ran successfully
for every target, or that all existing submissions were regenerated by the
current revision.

## Module Inventory

- Shared YAML parsing, adapters, stage orchestration and Slurm script generation
  are implemented in `models.py`, `adapters.py`, `orchestrator.py` and
  `script_builder.py` under `src/casp17/`.
- Protein template retrieval has separate sequence and structure stages;
  CCD classification, ligand fingerprints, filtering and USalign support the
  transfer of ligand-bound structural evidence.
- Docking adapters include Vina, AutoDock-GPU, Protenix-Dock and SurfDock;
  template-receptor and ligand-alignment tracks are coordinated by scripts.
  Adapter availability is separate from demonstrated use in the abstract.
- Research priors, symmetry/orientation handling, pose scoring and LG parsing
  support the final submission path. Ligand-series statistics and TS solvent
  tools are separate research/submission utilities.
- `mcp_server.py` exposes six tools: `status`, `validate`, `prepare_cofolding`,
  `list_presets`, `add_template`, and `create_input`. It does not currently
  expose a Slurm submission or complete workflow execution tool. The abstract
  does not claim an autonomous MCP prediction service.

## Scope Boundaries

- Affinity predictions and BA-Pred usage are excluded from the method narrative
  following the predictor's statement that they were not used. Generic code
  still contains affinity output options and missing-RMSD fallback paths.
  Their presence does not establish use in the reported method. The BA-Pred
  name remains in the published RMSD-Pred paper title only.
- Protenix-Dock is an optional implemented module. It is enabled in some local
  configurations, but the inspected representative output directory contained
  no result files. Do not infer successful use from the enabled flag.
- Ligand-series binder classification, retrospective AUC/BEDROC analysis,
  RNA-ligand prediction, and ordered-solvent TS methods have distinct workflows.
  They are not silently folded into this protein-ligand pose abstract.
- Local run configurations do not establish a universal database date cutoff.
  No unsupported claim of leakage-free evaluation or held-out results is made.

## Submission Metadata and Format

- `AUTO:N` is supported by research-driven selection and final human review.
- `TEMPL:Y`, `MSA:Y`, `DEEPL:Y`, `AF:AF3`, `EMA:Y` describe this workflow.
- `MD:Y` denotes docking energy functions under the supplied CASP definition;
  it does not assert molecular-dynamics simulation.
- `DIFF:AF3,Bolz2,Other` follows the spelling in the supplied CASP instructions;
  method prose uses Boltz-2. Protenix contributes the `Other` category.
- `CASP_SERV:N` and `RNA2D:N` retain the existing declared scope.
- `LLM:N` remains provisional pending confirmation of whether LLM-assisted
  target research influenced prediction decisions. Coding or abstract-writing
  assistance alone is not evidence of an LLM prediction component.
- Preserve group LCDD (129), the supplied author order/affiliations and email.
- Word output specifies Times New Roman 12 pt, single spacing, left-aligned
  sections, blank lines between body paragraphs, and consecutive references.
- A matching plain-text draft is generated. No figures are included. Actual
  Word pagination requires a renderer; LibreOffice is unavailable here, so
  the three-page limit is not yet visually verified.
